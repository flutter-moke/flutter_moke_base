# Flutter Moke Architecture

> **深度 · 记录 · 传播** — 探索 Flutter 架构的每个角落

---

## 专栏简介

**Flutter Moke Architecture** 是一套面向资深 Flutter 开发者的深度架构专栏。

从底层 ThemeData 扩展、自定义渲染对象，到 Navigator 2.0 路由体系与插件化动态化方案，本专栏以 **可运行源码 + 深度解析 + 性能实录** 的交付方式，帮助你把 Flutter 知识体系从「会用」推向「能造」。

> **moke 释义**：古英语中「墨」之意，寓意以笔墨记录技术沉淀。

---

| 阶段 | 主题 | 核心代码 |
